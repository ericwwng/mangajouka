# Introduction 
A manga website that filters out manga you already read.

# Setup
1. Install postgres
2. Install docker
3. Install rust
4. Install npm
5. `npm install -D vite`

# Development
1. Go to server/ and run `init_db.sh`
2. Go to server/ and run `cargo run`
3. Go to client/ and run `npm run dev`
4. Open up localhost:5173
